# Home Training V8

Base modular do Home Training.

## Novidades
- Progressão adaptativa por exercício: repetições/tempo aumentam conforme sessões concluídas.
- Exercícios podem chegar a 4 séries após evolução consistente.
- Biblioteca ampliada para peito, costas, ombros, braços, pernas, glúteos, posteriores, panturrilhas, core, HIIT, mobilidade, mochila, elástico e halteres.
- Treinos A/B/C preservam os grupos musculares definidos.
- GIFs são carregados remotamente, sem download manual, com URLs por exercício.
- Descobrir exibe a evolução de cada exercício quando houver.

## Mídia
A V8 usa URLs remotas de demonstração. Algumas vêm do ExerciseGymGifsDB via jsDelivr e algumas de Wikimedia Commons. Verifique as licenças das fontes antes de redistribuir o projeto.


## Feedback adaptativo
Ao concluir cada treino, o usuário pode avaliar a sessão como fácil, moderada ou difícil e escrever um comentário. O sistema aplica uma análise local por regras/termos ao feedback para ajustar a próxima sessão: aumentar levemente, manter ou reduzir intensidade/dificuldade. Comentários que mencionam sinais de alerta como dor ou tontura acionam uma redução preventiva. O histórico de feedback é salvo localmente.
